# SubagentPanel 子代理面板

阅读动线是任务上下文入口 → 全部子代理列表 → 某个子代理的历史对话 → 原列表。任务时间线中的具名子任务也可直接定位其详情。该面板用于阅读，不能提交、重试或推断执行结果。

## 列表和状态

Active、Needs attention、Done 按宿主提供的独立子任务状态分区。名称、头像、状态图标/文字和已有时间说明各司其职；不能仅用颜色或头像表示运行状态。Active 为零显示明确空态。完成组初始最多十项，过多时展开其余，提供收起入口；十项是本组件预览选择，不是全局限制。

运行、完成、需要确认是不同的事实。父任务完成不能将仍运行或未知的子任务改成 Done。宿主将失败/未知映射为准确的关注说明，不从最终文字推断状态，也不制造计时值。

## 历史与返回

宿主提供 selectedId 及实际历史 children。详情显示同一个任务的请求、过程、活动与最终结果；运行中可展示 Thinking，完成后展示已确认的耗时与结果，未确认时显示准确反馈，不假装完成。

列表在进入详情后仍挂载，保留多项展开和列表滚动；返回聚焦原子任务行，打开详情聚焦标题。关闭后宿主恢复原入口、主聊天草稿与阅读位置。open=false 时不抢焦点。宽窗与窄窗的区域分配归宿主。
