# 设计系统建设顺序与缺口

AReaL 已有生产控件、GUI 目录、状态合同和开发预览。当前共享目录提供原则、意图、Token 地图与决策。下一步要让设计选择、实际实现和验证结果相互对应，再用完整任务检验整体效果。本计划不表示以下能力已经实现。

## 当前基础与缺口

| 能力 | 当前基础 | 仍需完成 |
| --- | --- | --- |
| 产品设计语言 | [共享原则](principles.md)、[GUI 基础规则](../clients/gui/design-system/foundations.md)、现有图标与主题 | 完整候选的文字层级、表面、密度、形状、状态和动效选择，以及选择理由 |
| Token | [角色与平台映射](tokens.md)，GUI、TUI、Web 的现有数值源 | 选定首组需要共享的默认值，明确唯一编辑源、动态偏好优先级与平台输出 |
| 组件合同 | [生产控件](../clients/gui/renderer/src/components/ui)、[GUI 组件指南](../clients/gui/DESIGN_SYSTEM.md)与有限变体 | 为首批组件补齐就近的用途、状态、键盘、焦点、禁用语义与真实示例；Props 由类型提供 |
| 用户任务与组合 | [共享意图](intents.md)、GUI 的交互族、组合与 surface 合同 | 用一个完整候选验证工作区、对话、资源和设置能否共同组成连贯体验 |
| 文档与可运行示例 | [开发预览](../clients/gui/renderer/src/design-system/main.tsx)、现有 catalog 与生成器 | 将共享解释、组件合同和真实示例连接到同一阅读入口，避免文档示例与生产实现分别维护 |
| 变更约束与准入 | [目录检查](../clients/gui/scripts/design-system-catalog.mjs)、[增量审计](../clients/gui/scripts/design-system-changes.mjs)、GUI Base 候选 | 补足目录所声明接口与实际导出的核对，明确各端覆盖、版本兼容与准入；用真实任务验证行为与视觉 |

目前根目录的共享知识已建立，但 GUI 的 [Base 候选](../clients/gui/design-system/base.md)仍未冻结。现有目录主要检查引用与声明，不能证明实际 JSX 采用了对应组件，也不能代替视觉或平台验收。

## 先形成完整候选，再收敛实现

1. 固定一个完整设计版本。以提交任务、观察工具、处理决定、查看资源和返回阅读为主路径，同时安排一次外观设置修改。列出必要的失败与未知结果，固定明暗、字号和宽窄条件。交付可操作候选、关键状态和设计决定，先评价整体体验。
2. 明确首批基础角色。结合候选决定文字、表面、反馈、间距、形状和图标的使用关系。对 GUI、TUI 与 Web 分别登记适用范围，图形几何不强求终端等价。输出角色到当前实现的映射，明确哪些默认值需要共享。
3. 收敛一组 Token 与组件。先迁移候选实际使用的一组角色及 Button、Select、Switch、Feedback 等控件。共享默认值只有一处可编辑源，平台输出可重复生成并检查漂移。用户偏好保留运行时输入。迁移调用方后删除被替代定义，不同时维护两套数值。
4. 接通文档与真实示例。复用现有预览，展示组件状态、组合、主题、字号和平台限制。组件合同邻接组件，跨端理由归 `design/`，类型提供接口事实。面向人和 Agent 的目录由相同元数据生成，不另写一套 Props 或组件名单。
5. 迁移首条生产路径并复验。绑定原有业务控制器，分别检验权威结果、草稿与身份、阅读与焦点。跨端复用另取一个 TUI 或 Web 同意图场景，不能用 GUI 结果代替。完成后用另一种任务检查共享规则，再决定扩大 Base 准入。

共享默认值的生成格式在第二步确定。DTCG 可作为候选，但不为采用某种格式提前搬运所有数值。独立发布组件包、独立文档站和专用 Agent Skill 都不是首轮前提。先让现有生产组件、文档和示例形成可复验的最小闭环，有独立消费者或明确检索需求后再扩展。

## 首轮完成条件

- 同一候选覆盖工作区、对话、资源、设置及所选异常路径，整体视觉决定可审查。
- 所选 Token 和组件有明确所有者、真实消费者、状态合同与验证位置。
- 文档中的示例使用生产实现，目录生成与漂移检查通过。
- 行为、视觉、原生平台与安装包分别报告实际覆盖，未覆盖项保留。
- 原有调用方完成迁移，被替代定义删除，新增任务能复用同一设计选择。

本目录只维护中文。平台现有文档与外部用户文档继续遵循各自的维护约定，不在本轮批量删除既有译文。
